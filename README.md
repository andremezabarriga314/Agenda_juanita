## ✦ SOBRE EL PROYECTO

Agenda Juanita es una aplicación web desarrollada con Django y Python, enfocada en la gestión de agendas y administración de citas.

## 🚀 INSTALACIÓN

```bash
git clone https://github.com/andremezabarriga314/Agenda_juanita.git
cd Agenda_juanita

python -m venv venv
venv\Scripts\activate

pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
